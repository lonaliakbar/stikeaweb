Masuk Admin

Masuk dengan GitHub token untuk mengubah isi situs. Perubahan disimpan sebagai commit ke repo.

Cara membuat token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: pilih Only select repositories → repo situs ini.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Atur masa berlaku, buat token, salin, lalu tempel di atas.

Token hanya disimpan di browser ini (sesi, atau permanen bila “Ingat” dicentang) dan hanya dikirim ke api.github.com. Jangan masukkan token di komputer umum.
